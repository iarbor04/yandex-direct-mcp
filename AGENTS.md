# Правила работы с этим MCP-сервером

Инструкции для AI-агента, подключившего `yandex-direct-mcp`.

## Перед первым вызовом

1. `direct_status` — убедиться, что токен есть, доступ живой и понятно, боевая это среда или песочница. Ошибка 58 означает, что заявка на доступ не одобрена или токен получен под другим приложением: разбираться с этим, а не пытаться вызывать API дальше.
2. `direct_reference` — свериться с именами сервисов, методов и формой `params`. Не угадывать имена полей.

## Получение данных

- Статистика — только через `direct_report` (сервис Reports). Не собирать её из `get`-методов: это дороже по баллам и даёт другие цифры.
- `ReportName` делать уникальным для каждого запроса, иначе Директ вернёт ранее сформированный отчёт.
- `get` отдаёт максимум 10 000 объектов. Если объектов больше — идти постранично через `LimitOffset`, а не сокращать выборку молча.
- Следить за остатком баллов в шапке ответа. Если он тает быстро, сказать об этом пользователю, а не продолжать молча.

## Изменения

- Перед любым изменяющим методом (`add`, `update`, `delete`, `suspend`, `resume`, `moderate`, `set`, `setAuto`) показать пользователю, что именно будет изменено, и дождаться подтверждения. Изменения применяются к живому рекламному аккаунту сразу, отката нет.
- Массовые правки разбивать на пакеты и показывать результат каждого, а не отправлять тысячи объектов одним вызовом.
- Перед пакетной правкой ставок или бюджетов сохранять текущие значения, чтобы можно было вернуть.
- Номера объявлений (19 цифр) передавать строками, как они пришли в ответе: `{"Ids": ["1234567890123456789"]}`. Числом такой номер по дороге округлится и может указать на чужое объявление.
- Текстовые объявления — комбинаторные: создавать и править их через `ResponsiveAd` (до 7 заголовков и 3 текстов). `ads.update` с `TextAd` по такому объявлению оставит в нём один заголовок и один текст.
- Если сервер ответил, что включён режим «только чтение», — не пытаться обойти его через другие сервисы; сообщить пользователю.

## Деньги и единицы

- Ставки и бюджеты в API — в микроединицах: `30000000` = 30 ₽. При выводе пользователю переводить в рубли, при отправке — обратно.
- В отчётах суммы приходят в валюте аккаунта (сервер запрашивает их с `returnMoneyInMicros: false`).

## Безопасность

- Никогда не выводить содержимое токена, не копировать его в чат, файлы проекта, коммиты или логи. `direct_status` намеренно показывает только длину и последние символы.
- Не предлагать пользователю прислать токен сообщением. Для получения токена есть `save-token.sh` со скрытым вводом.
- Не отправлять данные рекламного аккаунта во внешние сервисы без явной просьбы пользователя.
